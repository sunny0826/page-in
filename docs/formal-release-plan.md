# v0.0.1 正式重发实施计划

单一 Agent 拥有本次图标、发布脚本、workflow、AGENTS.md、README、CHANGELOG 和发布文档；不启动子 Agent。已有放映代码只作为冻结源码的一部分验证。

| 阶段               | 依赖     | 工作与验收                                                                |
| ------------------ | -------- | ------------------------------------------------------------------------- |
| T0                 | 用户授权 | 完成 ADR、契约与计划，备份旧发布及标签；校验文档格式、链接和 whitespace   |
| T1                 | T0       | 更新构建来源参数、macOS provenance、正式版文档；静态校验脚本与流程        |
| T2                 | T1       | 全库检查通过；提交并推送源码，冻结 SHA                                    |
| T3 macOS           | T2       | 本地构建、签名、DMG / ZIP、manifest 和校验和；检查新图标                  |
| T3 Windows / Linux | T2       | 原生 CI 从同一 SHA 测试、构建并保存 artifact；无发布写入                  |
| T4                 | 两项 T3  | 汇总三平台包，验证文件清单、摘要和源码一致性                              |
| T5                 | T4       | 旧 Release 转草稿，按租约替换 tag 和全部附件；核验后正式公开并设为 Latest |
| T6                 | T5       | 更新发布验收记录，确认公开页面、下载摘要及待验证事项                      |

T3 为独立构建作业并行，不涉及多 Agent 文件写入。主 Agent 单线负责集成与发布。

风险：CI 或网络失败时继续保留旧公开发布，重试构建；进入 T5 后若失败则保持草稿，避免对外暴露混合包。旧附件与元数据在忽略目录中保留，旧 tag 对象保存为本地备份引用。此次单次重发不演变为默认允许移动已发布标签。
