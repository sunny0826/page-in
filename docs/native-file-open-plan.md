# 原生文件打开实施计划

## 依赖与所有权

本次单 Agent 串行交付，全部文件由当前负责人独占；不启动子 Agent。

| 阶段 | 依赖 | 文件与交付                                                          | 验收                                            |
| ---- | ---- | ------------------------------------------------------------------- | ----------------------------------------------- |
| T0   | 无   | ADR-009、契约、计划                                                 | 接口与范围冻结，链接/格式检查                   |
| T1   | T0   | Rust 请求队列、main.rs、build.rs、Cargo 与锁、Tauri 配置/capability | 请求来源、校验、单实例与关联测试                |
| T2   | T1   | 前端调度、main.ts、i18n、测试                                       | 串行、取消、模态与输入法边界                    |
| T3   | T2   | AGENTS、README、验证记录                                            | 全库 check、Clippy、前端/桌面包构建、macOS 实测 |

## 决策与风险

不拆并行波次，避免入口与队列的跨文件契约漂移。新增依赖只使用官方 single-instance 插件；如目标系统无法实测，明确保留待验收。禁止发布或移动现有标签，本次只实现与构建本地验证包。

## 验证门

门 A：`mise run check`、`cargo fmt --check`、Clippy、`npm run build` 与 Tauri app 构建。

门 B：macOS 系统文件打开冷/热启动、窗口拖放、未导出取消/继续、非法文件与原始文件字节不变；Windows/Omarchy 留作目标系统实测，不以 macOS 结果替代。

## 当前结果

实现、自动测试及 macOS 构建完成；2026-09-18 用户确认 macOS 手动验收通过并授权提交与推送。Windows/Omarchy 待实机验证，证据与范围详见[验证记录](native-file-open-verification.md)。
