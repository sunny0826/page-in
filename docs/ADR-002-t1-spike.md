# ADR-002：T1 技术原型范围

日期：2026-09-17。状态：macOS 原型已交付，三端验收未完成。

本 ADR 部分细化 ADR-001，不替换已定稿交互和最终软件架构。当前工作只交付 T1 可运行原型与本机证据，不宣称 Windows / Omarchy 或完整版本存储已经验证。

## 决策

- 环境以项目 mise.toml 固定 Node 24.12.0、Rust 1.92.0，所有开发命令通过 mise 执行；依赖使用 npm-lock 与 Cargo.lock。
- 用真实文件选择、一个系统 WebView、禁脚本 iframe、parse5 字节区间映射、Rust 补丁导出证明关键技术链路。
- T1 可编辑纯文本叶元素，混合父元素中有独立纯文本子元素时可编辑子元素。不可安全映射的内容只读。
- 实现会话内撤销/重做；仅提供“导出修改版”，不以临时内存或 localStorage 冒充正式版本库。SQLite、崩溃草稿、持久历史仍属 T4。
- 原型每次导出生成新文件，不允许覆盖原始文件。输入范围收敛为不超过 5 MiB 的有效 UTF-8 HTML；更大输入在本阶段明确拒绝。
- 仅允许用户明确授权的原 HTML 目录中的 CSS、图片、字体；远程资源不加载。资源路由采用独立协议，避免本地 HTTP 服务。
- 源码工作树已于 2026-09-17 按用户要求迁移至 `page-in` 项目目录；用户交付为源码包、macOS app 和验证报告，构建缓存不进入交付。

## 冻结的 T1 接口

open_document / open_sample → session + source；register_manifest → 已校验源区间；commit_edit → revision 与当前补丁；undo_edit / redo_edit → 文本状态；export_document → 成功的新文件路径。任意写操作校验 session 与 revision。

UI 接收到核心确认后才更新“导出成功”。关闭或切换有未导出修改时显示继续导出、放弃、取消。

## 替代方案与风险

不直接进入 SQLite 和完整版本功能，因为三端隔离与输入法尚未通过 T1 门槛。不用 DOM 序列化替代原文补丁。只读混合节点会降低初期覆盖率，但比破坏原始结构更合适。

同源 iframe 的父层事件、嵌套 CSP、WebKit 默认样式和资源协议需用实际 WKWebView 测试。混合标签输入、中文 IME、Omarchy/Windows 只能分别登记已测、失败或待测，不互相替代。

## 所有权与验收

本批为单一主实施者，所有源文件由其串行维护，不启用多 Agent。先完成 TS 和 Rust 契约测试与 release 构建，再跑本机实际应用操作。交付报告区分可执行结果、实测数据与待验证项。
