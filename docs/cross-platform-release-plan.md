# 跨平台预发布实施计划

主 Agent 单独拥有本次文档、.github/workflows/release-desktop.yml 与 scripts/package-ci-release.mjs。构建任务在 GitHub Actions 上并行运行，不启动子 Agent，不改应用源码。

| 阶段         | 依赖         | 交付与验收                                             |
| ------------ | ------------ | ------------------------------------------------------ |
| T0           | ADR-007      | 冻结跨平台发布契约、原标签和接口边界                   |
| CI 与包装    | T0           | 手动触发流程；原标签源码；mise；平台包及来源校验信息   |
| Windows 构建 | CI 与包装    | 版本、类型、自动测试、NSIS 打包通过                    |
| Linux 构建   | CI 与包装    | 版本、类型、自动测试、AppImage 与 deb 打包通过         |
| 单线发布     | 两个平台构建 | 校验所有附件，追加到现有 pre-release                   |
| 门 B         | 单线发布     | 远端状态、附件摘要和下载可用性；记录运行验收待用户执行 |

采用 GitHub 原生运行器，避免本机交叉编译工具链。保留已验证的 macOS 包和原有标签。构建失败先按实际日志修复构建流程；若需应用源码变更，必须说明来源偏离，不把不同提交伪装为原标签构建。

提交前验证 Markdown 格式、相对链接及 Git whitespace。构建脚本必须拒绝未知平台、缺失产物与源版本不符；发布任务必须确认目标仍为 pre-release，上传不使用覆盖参数。
