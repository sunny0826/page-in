# 原生文件打开契约

## 接口与职责

Rust `OpenRequests` 保存最多 32 个请求，每个请求包含随机 ID 与原生路径批次。路径只来自文件选择器、进程参数、macOS 文件 URL 或原生 Drop 事件。多文件批次拒绝；HTML 大小、后缀、UTF-8 校验与选择器共用。文件父目录是本次单文件资源授权范围。

- `pending_open_request() -> string | null`：查看队首 ID，无文件读取，无会话变更。
- `open_requested_document(requestId) -> Opened`：仅允许队首 ID，读取并暂存文档；沿用 `register_manifest` 激活会话。
- `dismiss_open_request(requestId) -> ()`：只删除匹配的队首，取消、失败、成功都调用。
- `open-requested`：无载荷唤醒通知；先注册监听，再查询队首，保证冷启动不漏事件。

前端在没有打开/关闭事务、IPC 操作、模态对话框、设置、菜单或输入法组合时处理队首。先结束原位输入，检查未导出修改；取消保留会话并删除该请求，失败保留尚未被替换的当前文档。完成一个请求后重新检查状态，再处理下一个。外部请求不覆盖现有对话框。

## 决策、替代与风险

只传请求 ID，避免通用路径读取接口。维持原权限边界，仅增加三个请求级 IPC 权限；不改变 iframe sandbox、资源类型或网络策略。原生 Drop 禁止浏览器默认导航；前端补充取消 DOM 文件 drop 默认行为。系统关联不会强制抢占浏览器默认设置。

队列满时保留已接收的请求，拒绝新增请求并发出错误通知。进程参数的相对路径以发起进程工作目录解析；`file:` URL 只接受本地文件，不接受网络 URL。macOS 系统文件事件独立于参数处理，避免同一文件重复打开。
