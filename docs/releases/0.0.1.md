# PageIn 0.0.1 Pre-release · 2026-09-18

PageIn 首版支持在本机直接修改 HTML 页面文字，并把演示项目连同图片、样式和脚本整体导出。原文件保持不变。

此版本为预发布。Windows 和 Linux 包先行提供下载，安装、启动、编辑与导出等待对应系统实机验证；Omarchy 请使用 Linux x64 AppImage。

## ✨ 亮点更新

- **原位文字编辑**：双击修改文字，支持换行标题的逐行编辑、撤销与重做。
- **HTML 演示文稿**：打开包含 index.html / index.htm 的项目文件夹，使用底部图标、方向键或滚轮翻页。
- **完整项目导出**：保留目录结构与全部资源，文字修改写入入口 HTML；普通单文件模式导出新的 HTML。
- **紧凑 macOS 界面**：内容铺满窗口，保留原生红黄绿按钮，工具栏独立悬浮；支持中文和 English。

## 🔧 稳定性与工程改进

- 修复 WKWebView 中选中文字后不能键入的问题。
- 修复移除脚本后文本节点合并导致的编辑位置偏移。
- 导出检查已有目标、源文件外部修改、越界路径和符号链接，避免覆盖原项目或漏掉资源。
- 版本号自动校验；发布包提供 SHA-256 校验文件与第三方组件声明。

## 📦 主要变更（按方向）

- **平台**：macOS 13+ / Apple Silicon（arm64）、Windows x64、Linux x64。尚不提供 macOS Intel、Windows ARM64 或 Linux ARM64 包。
- **安装包**：macOS 为 DMG / ZIP；Windows 为 NSIS `.exe` 安装程序；Linux 为 AppImage 和 `.deb`，后者仅适用于 Debian/Ubuntu。
- **签名状态**：macOS 使用 ad-hoc 签名，**未进行 Developer ID 签名及 Apple 公证**；Windows 安装程序未做代码签名。
- **验证**：macOS 已完成 28 项自动测试及 17 页演示项目的编辑、分页与导出实测。Windows / Linux 由原生 CI 执行自动测试、构建和包校验，**尚未完成桌面运行验收**。
- **构建来源**：各平台使用同一 `v0.0.1` 标签（`de217e61e9f3aeae3d2c7b874fa0c0ec5727855a`），不包含 main 后续 UI 样式提交。平台专属 manifest 记录 CI 来源和文件摘要。

## 安装与校验

- **macOS**：打开 DMG，将 PageIn.app 拖到 Applications；也可解压 ZIP。
- **Windows**：运行 `PageIn_0.0.1_windows-x64-setup.exe`。需要 WebView2；缺失时安装程序会联网下载。
- **Omarchy / Linux**：下载 `PageIn_0.0.1_linux-x64.AppImage`，赋予执行权限后运行：

  ```sh
  chmod +x PageIn_0.0.1_linux-x64.AppImage
  ./PageIn_0.0.1_linux-x64.AppImage
  ```

  若提示缺少 FUSE，可尝试 `./PageIn_0.0.1_linux-x64.AppImage --appimage-extract-and-run`。Wayland、图形驱动和实际桌面行为待用户验证。

原有 `SHA256SUMS` 与 `manifest.json` 对应 macOS 首批附件；新增平台分别使用 `SHA256SUMS-windows-x64.txt`、`SHA256SUMS-linux-x64.txt` 及对应 manifest。原有 `RELEASE-NOTES.md` 保留首批 macOS 包的说明，跨平台状态以本页和 `RELEASE-NOTES-cross-platform.md` 为准。

## 使用方法与当前边界

点击打开图标，选择 HTML 文件或项目文件夹；进入编辑后双击文字。Enter 提交、Esc 取消。导出图标或 ⌘S 创建新的文件／完整目录，请选择原项目之外的位置。

演示预览采用静态分页，不运行原页面 JavaScript、WebGL 动画或远程资源；导出保留原始代码与资源地址。只由脚本动态生成的内容、嵌套纵向幻灯片、任意混合父元素和带变换的文字编辑尚不支持。

HTML 入口限 5 MiB / 50,000 节点；项目导出限 512 MiB / 10,000 个文件和目录。尚不提供跨重启草稿恢复与自动更新。
