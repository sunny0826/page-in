# PageIn 0.0.1 · 2026-09-18

PageIn 是轻量的本地 HTML 原位文字编辑器。直接修改页面文字，保留原有排版与资源；支持 HTML 演示项目整体导出、全屏放映和内置动效。本正式版使用新的纸页与文字光标 logo。

## ✨ 亮点更新

- **原位文字编辑**：双击修改文字，支持换行标题、会话内撤销与重做。
- **完整项目导出**：打开含 index.html / index.htm 的文件夹，导出时保留目录结构、图片、字体和脚本，仅补丁修改入口 HTML 的文字。
- **全屏放映**：从当前页进入，隐藏顶部栏；演示项目分页，报告保持滚动，Esc 退出并恢复原先编辑/预览与全屏状态。
- **内置放映动效**：可信父页面提供入场、条形图和字符画布等适配，响应减少动态效果；编辑时停止，原页面 JavaScript 仍禁用。
- **界面与图标**：32px 紧凑顶部栏、macOS 原生窗口按钮、深绿与暖白配色、新应用 logo；支持中文与 English。

## 🔧 稳定性与工程改进

- 修复 WKWebView 中选中文字后不能键入，以及脚本移除引起的源位置映射偏移。
- 修复 WKWebView 不触发动画 finish 事件导致的两页重叠，处理快速前后翻页、动画取消和退出清理。
- 导出校验已有目标、外部文件变更、越界路径和符号链接，保留原文件及全部未改动字节。
- 三平台安装包使用同一完整源码 SHA；附 manifest、SHA-256、安装说明和第三方组件声明。

## 安装与校验

- macOS：打开 DMG，把 PageIn.app 拖入 Applications；也可解压 ZIP。
- Windows：运行 `PageIn_0.0.1_windows-x64-setup.exe`，缺少 WebView2 时安装程序会联网下载。
- Omarchy / Linux：下载 `PageIn_0.0.1_linux-x64.AppImage`，执行 `chmod +x PageIn_0.0.1_linux-x64.AppImage` 后运行。缺少 FUSE 时可尝试 `--appimage-extract-and-run`。
- Debian / Ubuntu：使用 .deb，不适用于 Omarchy。

macOS 使用 `SHA256SUMS` 与 `manifest.json`；Windows / Linux 使用各自带平台后缀的校验清单、manifest 和安装说明。以本页和当前 `RELEASE-NOTES.md` 为准。

## 当前边界

预览不执行原页面脚本、远程资源或原脚本驱动的 WebGL。内置动效不承诺与原脚本逐帧相同；导出保留原始脚本和资源引用。复杂混合、带变换且无法可靠映射的文字保持只读。

HTML 入口限制 5 MiB / 50,000 节点；项目导出限制 512 MiB / 10,000 个文件和目录。不提供跨重启草稿恢复或自动更新。
