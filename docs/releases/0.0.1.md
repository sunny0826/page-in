# PageIn 0.0.1 · 2026-09-18

PageIn 首版支持在本机直接修改 HTML 页面文字，并把演示项目连同图片、样式和脚本整体导出。原文件保持不变。

## ✨ 亮点更新

- **原位文字编辑**：双击修改文字，支持换行标题的逐行编辑、撤销与重做。
- **HTML 演示文稿**：打开包含 index.html / index.htm 的项目文件夹，使用底部图标、方向键或滚轮翻页。
- **完整项目导出**：保留目录结构与全部资源，文字修改写入入口 HTML；普通单文件模式导出新的 HTML。
- **紧凑 macOS 界面**：内容铺满窗口，保留原生红黄绿按钮，工具栏独立悬浮；支持中文和 English。

## 🔧 稳定性与工程改进

- 修复 WKWebView 中选中文字后不能键入的问题。
- 修复移除脚本后文本节点合并导致的编辑位置偏移。
- 导出检查已有目标、源文件外部修改、越界路径和符号链接，避免覆盖原项目或漏掉资源。
- 版本号自动校验；发布包提供 SHA-256 校验文件与第三方组件声明。

## 📦 主要变更（按方向）

- **平台**：macOS 13 或更新版本，Apple Silicon（arm64）。本次不提供 Intel、Windows 或 Linux 安装包。
- **安装包**：DMG 内含 PageIn.app 和 Applications 入口；ZIP 为同一应用的压缩副本。
- **签名状态**：使用 ad-hoc 签名校验包内资源，**未进行 Developer ID 签名及 Apple 公证**。此包用于早期手动测试分发，不保证通过 Gatekeeper 的开发者身份检查。
- **验证**：28 项自动测试；实测 17 页演示项目的编辑、分页与导出，24 个文件完整导出并核对哈希。

## 使用方法与当前边界

点击打开图标，选择 HTML 文件或项目文件夹；进入编辑后双击文字。Enter 提交、Esc 取消。导出图标或 ⌘S 创建新的文件／完整目录，请选择原项目之外的位置。

演示预览采用静态分页，不运行原页面 JavaScript、WebGL 动画或远程资源；导出保留原始代码与资源地址。只由脚本动态生成的内容、嵌套纵向幻灯片、任意混合父元素和带变换的文字编辑尚不支持。

HTML 入口限 5 MiB / 50,000 节点；项目导出限 512 MiB / 10,000 个文件和目录。尚不提供跨重启草稿恢复与自动更新。
