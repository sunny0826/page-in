# ADR-005：HTML 演示项目与整体导出

日期：2026-09-18。

## 决策与范围

在现有文字补丁模型上增加项目目录模式，保持原文件不可变。入口为根目录的 index.html / index.htm；不尝试将旁边的 slides.html 等生成中间文件同步重写。项目导出以当前入口的文字补丁为准，其他文件逐字节复制。

此前 ADR-002 的「仅单 HTML 导出」边界由本决策扩展。页面脚本不运行的隔离约束保留，不增加脚本权限或第三方运行时依赖。

备选方案是执行原脚本恢复播放或将所有页面转换为截图；前者会改变沙箱和源映射约束，后者失去文字编辑能力。因此采用静态 DOM 分页。2026-09-18 动效修订：替代此前“动画不播放”的限制，放映时由可信父页面使用 Web Animations 和 Canvas 2D 播放内置适配效果，按静态 `data-animate` / `data-anim` 与已知布局选择器识别；不解释、加载或执行原页面脚本。支持入场、横向翻页、条形图、卡片/矩阵/堆叠，以及 `canvas.ascii-bg` 字符背景；未知布局使用标记元素的淡入。保留放映中的原有 CSS 动画。普通预览和编辑保持静止；减少动态效果、切页、离开放映和换文档均清理动画。动态生成内容与任意 JavaScript 框架仍不受支持。Tauri 构建清单与可信主窗口能力表仅增加 open_project 命令，不向文档开放新的 API。

## 契约

- Rust Session / Opened 新增 project 布尔值；open_project 通过原生目录选择器确定资源根与入口。register_manifest、文字补丁和撤销沿用现有事务。
- 可信外壳识别平级幻灯片容器，在映射完成后给预览副本增加显示状态和样式。键盘、按钮与滚轮只改变当前页索引，不改变文档修订号。
- 放映模式适用于当前打开的报告或 HTML 演示文稿：从当前页进入原生全屏，完成正在编辑的文字事务后切换为只读预览，隐藏顶部栏并让页面使用整个窗口。PPT 沿用现有翻页适配；报告保留滚动阅读。`F5` / 纯图标按钮进入，`Esc` / 退出图标离开；移动鼠标显示控制栏，闲置 2.2 秒隐藏，悬停或键盘焦点位于控制栏时保留可见。进入失败不隐藏外壳；退出恢复之前的编辑/预览与窗口全屏状态。系统退出全屏时同步退出放映。放映不改变修订号或导出内容，进入前完成文字编辑所产生的提交仍按原规则处理。
- 主窗口 capability 为放映仅增加 `core:window:allow-is-fullscreen` 与 `core:window:allow-set-fullscreen`；不启用默认权限集，不授予文档脚本或文件权限，iframe 的静态沙箱保持不变。全屏切换串行执行；进入等待宿主确认，主动退出则先恢复外壳，窗口切换失败时仍保留操作按钮并显示错误。放映期间每 300ms 同步原生全屏状态，避免系统最后一次 resize 早于全屏动画结束时漏掉退出；离开放映后停止检查。退出超时不得反向请求重新进入全屏。
- HTML 导入时从净化后的静态结构识别文档类型：`#deck`、`.slides`、`.slide-deck` 中有直接子级 `section` / `.slide`，或同一父节点下至少两个 `section.slide`，标记为「PPT」；其余连续页面标记为「报告」。不依据文件名或正文关键词判断。该分类是展示用启发式，不代表原生 PowerPoint 格式；单页及嵌套演示可标记，但翻页仍限现有适配范围。中英文标记在预览及编辑顶部栏显示，切换文档时更新，加载失败清空页面时同步清空；不写入原文件或导出内容。
- 仅含文本和 br 的标题/段落会在解析副本中包装文本行，保留原始文字区间；导出不带包装标签或预览控制代码。
- 导出先将全部文件构建到目标父目录下的临时目录，再校验会话与修订号，独占创建新目录并发布内容。发生失败不标记为已导出。
- 拒绝覆盖已有路径、导出到源项目内、符号链接、特殊文件、超限项目以及外部已修改的入口。静态预览不是任意 JavaScript 演示框架的运行容器。

## 验收

自动化覆盖换行标题的源位置与 br 保留、完整目录/空目录/二进制资源复制、已有目标保护、外部入口修改和符号链接拒绝。实机验收使用用户给定的 17 页项目，核对翻页、文字编辑、整体导出及所有未修改文件的哈希。

2026-09-18 放映模式验证：28 项前端测试（包含 5 项全屏状态机测试）、9 项 Rust 测试、类型检查和 macOS Release `.app` 构建通过。Chromium 使用模拟窗口 IPC 跑通真实前端导入、放映按钮 / F5、方向键翻页、闲置隐藏、Esc 退出、编辑模式恢复、报告滚动、保留进入前全屏状态及系统退出全屏的同步；这些操作未调用文字提交、历史或导出命令。浏览器模拟不证明原生全屏动画或系统 WebView 输入正常。当前桌面控制工具仍只能访问旧 T1 原型，新构建的原生全屏、输入法及跨平台回归均待实测。

退出修复：用户反馈返回窗口后操作栏全部消失。使用延迟窗口 IPC 复现：最后一次 resize 检查时仍为全屏，之后原生状态变为非全屏但不再发送 resize，旧实现保持 `presenting=true`、顶部栏隐藏。修复后自动恢复 32px 顶部栏；补充慢退出、退出失败、状态查询暂时失败和停止轮询的回归。31 项前端测试和 9 项 Rust 测试通过；浏览器模拟验证延迟系统退出、Esc 慢退出及原生拒绝退出时操作栏均可恢复，原生系统动画回归仍待实测。

翻页重叠修复：macOS 系统 WKWebView 中，禁用脚本 iframe 的动画 `finish` 事件未触发，而 `finished` Promise 正常兑现。旧实现只在 `onfinish` 隐藏旧页，动画不保留端点，导致结束后两页叠在原点。改用可信父页面 Promise 收尾，保留过渡端点到旧页隐藏后再取消动画，并使收尾幂等以隔离快速翻页的过期回调。系统 WebView 的复现和回归证据见 [演示验收](presentation-verification.md)。
