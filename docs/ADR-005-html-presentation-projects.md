# ADR-005：HTML 演示项目与整体导出

日期：2026-09-18。

## 决策与范围

在现有文字补丁模型上增加项目目录模式，保持原文件不可变。入口为根目录的 index.html / index.htm；不尝试将旁边的 slides.html 等生成中间文件同步重写。项目导出以当前入口的文字补丁为准，其他文件逐字节复制。

此前 ADR-002 的「仅单 HTML 导出」边界由本决策扩展。页面脚本不运行的隔离约束保留，不增加脚本权限或第三方运行时依赖。

备选方案是执行原脚本恢复播放或将所有页面转换为截图；前者会改变沙箱和源映射约束，后者失去文字编辑能力。因此采用静态 DOM 分页，接受动画不播放的限制。Tauri 构建清单与可信主窗口能力表仅增加 open_project 命令，不向文档开放新的 API。

## 契约

- Rust Session / Opened 新增 project 布尔值；open_project 通过原生目录选择器确定资源根与入口。register_manifest、文字补丁和撤销沿用现有事务。
- 可信外壳识别平级幻灯片容器，在映射完成后给预览副本增加显示状态和样式。键盘、按钮与滚轮只改变当前页索引，不改变文档修订号。
- 仅含文本和 br 的标题/段落会在解析副本中包装文本行，保留原始文字区间；导出不带包装标签或预览控制代码。
- 导出先将全部文件构建到目标父目录下的临时目录，再校验会话与修订号，独占创建新目录并发布内容。发生失败不标记为已导出。
- 拒绝覆盖已有路径、导出到源项目内、符号链接、特殊文件、超限项目以及外部已修改的入口。静态预览不是任意 JavaScript 演示框架的运行容器。

## 验收

自动化覆盖换行标题的源位置与 br 保留、完整目录/空目录/二进制资源复制、已有目标保护、外部入口修改和符号链接拒绝。实机验收使用用户给定的 17 页项目，核对翻页、文字编辑、整体导出及所有未修改文件的哈希。
