# macOS 融合式窗口顶部验收

日期：2026-09-17。

后续调整：已根据用户反馈移除下述 64px 顶栏与正文偏移，改为全窗口内容和独立紧凑浮栏。此文保留初版验收记录；当前实现见 README。

## 实现

- Rust 窗口使用 `TitleBarStyle::Overlay`、`hidden_title(true)`；保留系统 decorations、原生关闭/最小化/全屏按钮，不绘制仿制按钮。
- 请求原生按钮坐标 `(20, 32)`；页面顶部保留 64px，品牌与工具栏始终避让左侧 112px。原生系统可能在缩放或屏幕共享时调整按钮显示位置，整块区域均可容纳。
- 欢迎页标题区域与文档顶部空白区域使用 Tauri drag region；仅增加拖动与内部双击缩放权限。
- iframe 和可信输入层同步下移，原有命中检测以 iframe 的实际矩形为基准，不硬编码页面文字偏移。
- 所有窗口配置及页面布局差异仅用于 macOS。

## 验证结果

- TypeScript 检查、13 项前端测试、6 项 Rust 测试、Rust 格式检查通过；macOS release app 打包成功。
- 重启新版后，欢迎页不再出现原生标题文字；文档状态下原生红黄绿按钮与工具栏位于页面顶部，正文不受遮挡。
- 在下移后的示例标题处双击，实际键入 `Window chrome check` 并按 Enter：正确提交。点击撤销恢复原文及未修改状态。
- 点击原生关闭按钮会触发未导出提示；取消后测试文字仍然保留。
- 顶部空白区域双击后窗口扩大，调用原生绿色按钮的缩放动作后恢复原尺寸。
- 顶部拖动动作执行无错误；工具未提供窗口位置，未独立断言移动距离。窄窗口、全屏切换及最小化尚未专项验收。
- 最终示例已撤销测试修改，原文件未更改。屏幕共享指示器在部分截图中覆盖了红黄绿按钮；恢复常规尺寸后的截图已能看到原生按钮。

产物：`src-tauri/target/release/bundle/macos/PageIn.app`。
