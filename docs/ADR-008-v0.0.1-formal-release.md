# ADR-008：v0.0.1 当前源码正式重发

日期：2026-09-18。

## 决策与替代范围

用户明确选择“仍用 v0.0.1 发布当前代码，明确允许替换旧标签与全部安装包”。此次作为单次例外，取代 [ADR-007](ADR-007-cross-platform-prerelease.md) 中保留旧标签、旧附件和 pre-release 状态的约束；包含当前放映功能、界面改进和新应用 logo。原文件不可变、静态沙箱、版本一致、签名声明和真实验收边界继续有效。

先备份旧 Release 元数据、全部附件和 annotated tag 对象。冻结新的完整源码 SHA，macOS 本地构建与 Windows / Linux 原生 CI 均从该提交构建。CI 只生成可下载 artifact，不改 GitHub Release。全部包校验通过后，短暂将旧 Release 转为草稿，使用带旧 tag 对象租约的更新替换 v0.0.1，替换全部附件并验证，再发布为非草稿、非预发布和 Latest。

正式发布是用户的分发决策，不代表新增平台实机证据。Windows / Omarchy 安装、启动、编辑、放映与导出仍待验证；macOS 全屏及完整原生输入未在本次重新验收。说明中必须保留这些边界。

## 替代方案与风险

- 发布 v0.0.2 可保留已发布版本不变，用户已明确不采用。
- 仅转正旧版不会包含新 logo 与放映功能，不满足本次选择。
- 同名标签和附件替换会使旧下载缓存、旧校验和与旧 clone 不再代表当前发行；发布说明显式披露旧源码 SHA 和替换事实，不隐瞒历史。
- 切换期间下载可能短暂不可用；失败则保持草稿并修复或依据备份恢复，不公开混合来源的附件。

## 验收

门 A：版本一致、类型检查、前端与 Rust 测试、Rust 格式及 Clippy、本地 macOS 和 Windows / Linux 原生构建通过。

门 B：所有包来自同一源码 SHA；PNG/ICNS/ICO 为新 logo；macOS 签名与 DMG/ZIP 完整性检查、三平台 manifest/校验和与 GitHub 附件摘要一致。记录实际完成的桌面验证与待验证项，不以 CI 替代实机。
