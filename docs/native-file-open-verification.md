## 手动验收

先退出正在运行的 PageIn，使用 `src-tauri/target/release/bundle/macos/PageIn.app`。本次源码与旧安装包不同，避免选中 Applications 或已挂载 DMG 中的旧副本。

| 场景           | 操作                                                      | 预期                                         |
| -------------- | --------------------------------------------------------- | -------------------------------------------- |
| 冷启动         | 退出 PageIn；HTML 的“打开方式 → 其他”选中新构建           | 自动启动并显示指定文件；中文、空格文件名正常 |
| 双击           | 自行将新构建设为 HTML 默认应用后双击 HTML                 | 打开该文件；不需再点应用内打开图标           |
| 热启动         | PageIn 已运行时，用系统打开另一个 HTML                    | 复用现有窗口，展示新文件                     |
| 拖放           | 拖入单个 `.html` / `.htm`，分别覆盖欢迎页、预览与编辑模式 | 打开文件，不发生浏览器默认跳转               |
| 未导出取消     | 编辑文字后拖入另一文件，选择取消                          | 当前文件及修改保留                           |
| 导出后继续     | 编辑后系统打开另一文件，选择导出后继续                    | 导出新文件成功后切换；取消导出则保留当前文件 |
| 丢弃后继续     | 编辑后打开另一文件，选择放弃修改                          | 切换新文件，原文件字节不变                   |
| 模态与连续请求 | 设置/确认框打开时发起系统打开，再关闭弹窗；连续打开文件   | 等待现有弹窗，逐个处理请求，不覆盖确认框     |
| 错误输入       | 拖入 txt、目录、多个 HTML、超过 5 MiB 或非 UTF-8 文件     | 提示错误，保留当前文档                       |
| 输入回归       | 键盘替换、退格、Enter、Esc、中文输入法组合后换文件        | 输入正常，组合期不被外部打开中断             |
| 保真           | 编辑中文/Emoji，导出并比较                                | 原文件不变，导出仅改变对应文字字节区间       |
| 放映           | 放映期间打开/拖入 HTML                                    | 退出放映后走正常打开确认流程                 |

Windows 与 Omarchy 未实机验证；需分别验证安装文件关联、已有进程转发、拖放与未导出处理。AppImage 需要系统桌面集成，不能把 AppImage 可运行等同于已经注册默认打开方式。
