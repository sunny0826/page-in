# 设置、语言与图标操作验收

日期：2026-09-17。

## 界面变更

- 窗口名称改为 `PageIn`；应用界面、错误提示不再显示阶段代号或技术原型文案。历史设计文档仍保留当时的背景记录。
- 预览时右上角为编辑、打开新文件和设置三个图标。编辑状态保留文件状态，撤销、重做、预览、导出、打开、设置均为图标。
- 欢迎页、提示及确认弹窗的操作按钮统一使用 Base UI 图标按钮，保留 Tooltip 和 `aria-label`。导入 HTML 的原始按钮及文字不作改变；原生系统文件选择器遵循操作系统界面。
- 设置为可键盘操作、可滚动的 Base UI Dialog，包含中文 / English 原生单选项和诊断信息。界面文字即时切换，偏好用 `pagein.locale.v1` 保存在本地；存储不可用时仍可切换当前会话语言。
- 界面文案、编辑提示、未导出提醒、已知文件错误和应用提供的原生文件选择器标题均有中英文版本。操作系统产生的错误与系统控件遵循系统语言。
- 设置打开前提交当前文字事务；确认弹窗会关闭设置，避免两个模态层同时处理输入。设置开启时编辑快捷键暂停。

## 验证

- TypeScript 检查通过；17 项前端测试、6 项 Rust 测试通过；Rust 格式检查及 macOS release 打包通过。
- 新增测试覆盖语言持久化、无效/受限存储、英文错误翻译、路径插值保真，以及从设置进入未导出保护的模态状态。
- 原生 macOS 实测中文设置 → English：标题、说明、诊断标签即时更新；Esc 返回后欢迎页和按钮无障碍名称均为英文。
- 关闭并重新启动应用，英文选择仍保留。
- 预览工具栏截图确认只有三个图标；进入编辑后真实键入 `Icon toolbar check` 并提交，打开新文件先出现英文未导出提示，三个操作按钮均只显示图标。
- 取消保护提示后文字仍在；点击撤销恢复原文，再通过右上角文件图标和系统选择器打开 `tests/fixtures/self-contained.html` 成功。
- 设置诊断显示 `self-contained.html`、10 / 10 可编辑片段以及本次解析和启动时间。切回中文立即生效。
- 测试修改已撤销，原 HTML 未修改；最终语言恢复中文。未执行 Windows/Linux 实机验收。
